# План задач: Distill-style Explorable Explanation

## Цель
Собрать интерактивную веб-статью "The Determinism Gap", которая объясняет:
- почему у LLM возможен дрейф вывода даже при `temperature=0`;
- как подход Batch Invariance устраняет источник недетерминизма на уровне редукций.

## Общие правила реализации
- Без fallback-логики для обязательных данных и конфигов.
- Fail-fast на невалидных входах и состояниях.
- Никаких silent-except; ожидаемые ошибки логировать с контекстом и пробрасывать дальше.
- Без скрытых ретраев.
- Любое изменение глобального состояния мгновенно отражается во всех интерактивах.
