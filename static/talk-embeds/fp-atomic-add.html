Same 8 numbers every race — four magnitudes and their negatives, exact sum 0. Each core finishes whenever the scheduler gets to it, so the arrival order at the accumulator changes race to race. Floating-point addition isn't associative, so a different arrival order can round to a different final sum — the same nondeterminism as the mosaic, now shown at the level of a single atomic add.
