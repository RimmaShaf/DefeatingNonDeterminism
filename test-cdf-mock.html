Same prompt, 100 runs, per-token comparison.

Read this before the charts

Unit asymmetry. Gemini exposes no token IDs, so its divergence index is measured in UTF-8 bytes and Unicode codepoints — both are shown, overlaid. Ollama (local) and Groq report divergence in tokens, using each model's own tokenizer. A "divergence at index 12" means something different across rows below — do not compare magnitudes across providers.

Ollama — local, tokens

Unit: token index. Tokenized via each model's matching HF tokenizer; model digest captured from /api/show.

Gemini — hosted, byte + codepoint

Unit: UTF-8 byte index and Unicode codepoint index, overlaid per tile. No token IDs are exposed by the API.

Groq — hosted, tokens

Unit: token index. Token strings taken from logprobs where available, else re-tokenized with the Llama-3.3 vocabulary.

Each tile: histogram of pairwise first-divergence indices (bars) with the empirical CDF (line) overlaid. Median is the 50th percentile of C(n_ok, 2) pairwise comparisons. T=0 tiles are controls — under a fixed seed they should collapse near the right edge (no early divergence). Tiles with n_ok < 50 carry a low-sample warning; their curves are statistically noisy.
